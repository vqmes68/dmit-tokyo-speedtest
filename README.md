# DMIT 日本测速：东京 Pro 与 T1 的测试 IP、Looking Glass 实操流程，以及测完怎么选套餐

买 VPS 之前先测线路，这件事在日本机房上尤其重要。东京离国内近是事实，但"近"不等于"快"——同样一台东京机器，走 NTT 普通国际线路和走 CN2 GIA 回程，晚高峰的体验可以差到像两个机房。所以搜「DMIT 日本测速」的人，想解决的问题基本是同一个：**先别急着付款，用官方的测试 IP 和 Looking Glass 把东京节点的延迟、路由和速度跑一遍，再决定买哪条线路。**

这篇就把这件事按步骤讲清楚，包括 DMIT 东京现在在卖的线路、官方测试地址、怎么看懂路由结果，以及测完之后套餐该怎么对号入座。

## 先分清线路：DMIT 东京现在卖的是什么

DMIT 在日本东京机房（Equinix TY8）的产品按网络类型分档，这个分类决定了你测速时会看到完全不同的数字：

- **TYO.Pro（Premium）**：回程 CN2 GIA，搭配联通 AS9929/AS10099 精品网和移动 CMI，去程也做了优化。三网深度优化，1Gbps 端口，流量超出后**暂停服务**。这是东京的旗舰档。
- **TYO.T1（Tier 1）**：纯国际互联，电信联通走 NTT，移动走 CMI，部分路由会绕美走 Lumen。没有针对中国大陆的优化，流量超出后**限速不停机**（比如 WEE 降到 50Mbps 继续用）。
- **TYO.EB（Eyeball）**：曾经存在的 CMI 优化档，但按多个来源的说法，这个系列目前在官网已经看不到，处于下架或缺货状态。如果你在旧文章里看到 EB 的价格，先别当真。

硬件层面两条线是同一平台：KVM 虚拟化，AMD EPYC 7003（Milan）处理器，NVMe SSD，标配 1 个 IPv4 和 1 个 IPv6 /64。差别只在线路和流量策略，不在机器本身。

## DMIT 日本测速要用的两个官方地址

### 测试 IP

想测去程（你的电脑到东京服务器），直接 ping 这两个 IP：

| 节点 | 测试 IP | 线路定位 |
| --- | --- | --- |
| 东京 Pro | `154.12.190.32` | 三网 CN2 GIA 优化 |
| 东京 Tier 1 | `154.31.112.5` | 国际线路，无大陆优化 |

命令没什么花样：


ping 154.12.190.32


看两个数：延迟（ms）和丢包率。丢包 0% 是理想状态，晚高峰连续测几次，如果丢包稳定在 5% 以上，基本可以放弃这条线路了。

### Looking Glass

只 ping 一个 IP 只能看到去程，回程怎么走是看不到的。DMIT 的 Looking Glass 部署在 `lg.dmit.sh`，东京节点可以直接用 `https://lg.dmit.sh/?server=tyo-pro` 和 `?server=tyo-t1` 打开。

它的价值在于**从服务器往外测**——也就是站在东京机器的角度看数据包回国经过哪些节点。普通 ping 测不到这一段，而晚高峰卡不卡，恰恰取决于这一段。

页面支持三种命令：

- **Ping**：基础延迟和连通性
- **Traceroute**：看回程路径经过哪些骨干节点
- **MTR**：Ping 和 Traceroute 的结合，能定位到具体是哪一跳开始丢包

## 把测速做完整：四步流程

**第一步，本机 ping 测试 IP。** 建议在不同时段各测一次，尤其是晚上 8 点到 11 点这段。你本机的结果只代表你所在的运营商和城市，和别人测出来的数字本来就不该一样。

**第二步，打开 LG 跑 Traceroute。** 先查自己的公网 IP（`ip.sb` 之类的服务都行），填进 LG 的目标 IP 栏，选择 Traceroute，运行。

**第三步，读懂路由结果。** 这里有几个关键 AS 号，看着眼熟就行：

- **AS4809 / 59.43.x.x**：电信 CN2 骨干。看到 `59.43` 开头的地址，说明回程走了 CN2，这是电信方向的优质路径。
- **AS23764**：中国电信国际（CTG）。东京 CN2 GIA 的回程通常会先经过它，再接入 59.43 骨干。
- **AS9929**：联通精品网，联通方向的好线路。
- **AS58453**：移动 CMI，移动用户的优质出口。
- **AS4134 / AS163**：电信普通 163 骨干，延迟明显高于 CN2。
- **AS4837**：联通普通线路。

**第四步，有丢包就上 MTR。** 逐行看 Loss% 那一列，哪一跳开始出现持续丢包，问题就出在那一段。单次 MTR 的偶发抖动不用太当真，跑个十几分钟看稳定值。

**想测下载速度**，可以进机器后用 speedtest-cli 或者 iperf3 对着国内节点跑单线程。单线程比多线程更接近真实体验——多线程跑满容易产生"速度很好"的错觉。第三方评测里 TYO.Pro 在 500Mbps 档位的机器上单流能跑到 540–570Mbps，说明端口承诺是能兑现的，但这属于他人实测数据，你自己的结果仍取决于本地网络。

## 测出来什么样算合格

没有统一标准，但有两条判断线：

1. **延迟**：东京节点对国内本来就有地理优势，实际数字取决于你的运营商的回国路径。同一个 IP，上海和成都、电信和联通出来的结果都能差出一大截。别拿别人的截图当基准，看你自己的晚高峰数据。
2. **路由是否稳定**：延迟低但抖动大，比延迟略高但稳定要难受得多。要的是 MTR 跑下来曲线平、没有孤立丢包跳。

如果你的主要用途是国内用户访问，Pro 的回程 CN2 GIA 是这套测试里唯一能给出确定性答案的选项。T1 测出来数字好看的时候通常是非高峰时段，晚高峰绕美是常态，这不属于故障，是产品定位本身决定的。

## 几个常见问题

**测试 IP ping 不通，是机器挂了吗？**
不一定。部分运营商或防火墙策略会屏蔽 ICMP，先在 LG 上从服务端方向测一次，看目标是否可达。LG 能跑通说明机器是活的。

**我 ping 东京 40ms，别人 25ms，是买到差的线路了？**
大概率只是你们不在一个城市、也不是同一个运营商。延迟由物理距离和回国路径决定，跨运营商比较没有意义。

**Looking Glass 能代替下载测速吗？**
不能完全代替。LG 给的是延迟和路由质量，带宽能不能跑满得靠实际传输看。两者都做，结论才完整。

**东京还有 Eyeball 系列吗？**
按目前多个来源的说法已经查不到，属于下架或缺货状态。如果后面重新上架，测试方式和 Pro 一样，用对应节点的测试 IP 就行。

**Pro 流量跑超了会怎样？**
暂停服务，不像 T1 那样降到低速继续用。如果你流量估算不准，这一点要提前算好，或者干脆选 T1 系列。
